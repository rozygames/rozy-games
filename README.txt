ROZY GAMES — KERANGKA WEBSITE
================================

Struktur:
- index.html                 Beranda
- ps3.html                   Katalog PS3
- ps4-hen.html               Katalog PS4 HEN
- ps5-hen.html               Katalog PS5 HEN
- subtitle-indonesia.html    Katalog Subtitle Indonesia
- harga.html                 Daftar harga isi game
- servis.html                Daftar layanan servis
- css/style.css              Desain website
- js/main.js                 Menu HP dan pencarian katalog
- images/                    Tempat logo/banner
- covers/                    Tempat cover game

UPLOAD KE GITHUB PAGES:
1. Buat repository baru bernama rozy-games (Public).
2. Ekstrak ZIP ini.
3. Upload semua ISI folder rozy-games ke halaman utama repository (root).
4. Buka Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu GitHub menerbitkan website dan buka alamat yang ditampilkan.
