# Cover Katalog PS5 HEN

Unggah gambar cover game PS5 ke folder ini.

Gunakan nama file sesuai judul game dalam format huruf kecil, tanda spasi menjadi tanda hubung, dan ekstensi `.jpg`.

Contoh:
- `astro-bot.jpg`
- `black-myth-wukong.jpg`
- `demon-s-souls.jpg`

Katalog PS5 HEN akan membaca gambar secara otomatis dari folder ini. Jika gambar belum tersedia, judul game tetap ditampilkan.
